# Welcome to Agneax OS

Agneax OS is a modern, lightweight, and elegant Linux-based operating system designed for productivity, focus, and visual delight. Built for developers, designers, and everyday computer users, Agneax OS combines dependable system performance with a carefully crafted desktop experience called **Agneax Desktop**, powered by **Agneax UI**.

---

## Highlights

- **Refined User Experience**: Clean visual hierarchy, consistent typography, and smooth transitions powered by Agneax UI.
- **Efficient & Responsive**: Engineered to consume minimal system resources while maintaining fluid 60 FPS system animations.
- **Integrated Application Suite**: Out-of-the-box file management, terminal, text editing, software management, and multimedia tools tailored specifically for the system.
- **Fast Application Runtime**: Enhanced internal application management for near-instant cold and warm app launches.
- **Production-Ready Base**: Grounded on a solid, battle-tested Linux foundation with long-term kernel stability and regular security updates.

## Getting Started

1. Visit the [Download Section](https://github.com/agneax/agneax-os-docs/releases) in our documentation repository.
2. Verify the SHA256 checksum of your downloaded ISO.
3. Flash the image to a USB flash drive (minimum 8 GB).
4. Boot into the live environment and run the visual installer.

For a full step-by-step walkthrough, read our [Official Installation Guide](https://github.com/agneax/agneax-os-docs/blob/main/docs/04-installation.md).
